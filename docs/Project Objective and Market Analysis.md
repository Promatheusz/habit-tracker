# Project Objective And Market Analysis

## Product Vision

Habit Tracker RPG is a web application that turns habit tracking into a lightweight role-playing progression system. Users create habits, complete them, earn XP and currency, level up, and spend currency on rewards. The goal is to make routine self-improvement feel more immediate, visible, and motivating.

## Scope

The project covers:

* User registration and login.
* Habit creation, editing, completion, and soft-delete.
* XP, level, and currency mechanics.
* Reward shop and purchased reward history.
* Dashboard, habits, rewards, and profile screens.
* Dockerized React, Express, and SQLite implementation.
* Markdown and Mermaid project documentation.

The project does not aim to be a full commercial productivity platform. It focuses on a complete academic prototype with clear architecture, working workflows, and documented requirements.

## Market Need

Many habit trackers and to-do applications lose user attention because they provide limited feedback after task completion. Habit Tracker RPG addresses that gap by adding immediate rewards, visible progression, and unlockable incentives. This makes habit completion feel closer to a game loop while keeping the interface focused on daily productivity.

## Target Users

The main audience is young adults, university students, and remote professionals who want structure, motivation, and a stronger sense of progress in everyday routines.

## Product Value

The value of the project is the combination of simple habit management with RPG-style reinforcement:

* Habits become trackable quests.
* XP creates long-term progress.
* Currency creates short-term reward motivation.
* Rewards connect digital progress with real-world incentives.
